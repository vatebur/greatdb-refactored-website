// 关键技术特性
高可靠
通过多数派协议保证副本的一致性，通过组复制机制保障组件的高可用；支持同城多中心和异地灾备部署方式，可以做到 RPO=0，RTO < 60s。
数据安全
提供企业级数据安全特性，包括密码复杂度、账户增强、访问控制，同时提供国密算法存储加密和通信加密，保障数据安全。
便捷运维
提供运维管理平台，覆盖数据库全生命周期管理，简化日常运维；提供 Oracle 迁移、评估功能，协助用户进行迁移操作。
高兼容
完全兼容 MySQL 生态，基于 MySQL 的业务程序可以无缝迁移到 GreatDB；兼容 Oracle 特性，包括递归查询、窗口函数、序列等。
高性能
优化 InnoDB 引擎，提升事务吞吐与并行查询优化性能；优化 MGR 架构，大幅提升性能吞吐与稳定性，提供透明读写分离，实现读扩展。
国产化
支持国产芯片：龙芯、申威、飞腾、鲲鹏、海光、兆芯；支持国产操作系统：麒麟软件、统信UOS、openEuler、麒麟信安、TurboLinux 等。
